# Mini Projeto: Sistema de Pedidos Simples (JavaScript + Padrões de Projeto)

Este projeto demonstra o uso de vários padrões de design (Singleton, Factory, Strategy, Observer, Repository, Command).

## Execução
1. Certifique-se de ter o Node.js instalado.
2. No terminal, execute:
   ```bash
   node app.js
   ```

## Padrões implementados
- **Singleton:** configuração global
- **Factory:** criação de produtos
- **Strategy:** estratégias de desconto
- **Observer:** notificação de eventos
- **Repository:** armazenamento de pedidos
- **Command:** encapsulamento da ação de criar pedido

## Resultado esperado
Mensagens de log e tabela de pedidos simulados no console.
